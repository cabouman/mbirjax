Does dropping the first full-volume iteration change the reconstruction?

Contents: Overview · Data and methods · What to look for · lilly_ds8 · z62 · lilly_ds4 · Center-slice zoom · Provenance

Overview and summary

MBIRJAX's default VCD schedule ([0,2,4,6,7]) begins with a granularity-0 iteration: a single subset containing every voxel cylinder, i.e. a full-volume update. That first iteration is the memory high-water mark of the whole reconstruction, and we would like to drop it. The skip 0 candidate ([2,4,6,7]) simply starts at granularity 2 (4 subsets) instead. This page shows head-to-head reconstructions — same data, same regularization, same iteration count; the only difference is the schedule.

Bottom line: on three real datasets at two sharpness settings, default and skip 0 are visually indistinguishable at 15 and 20 iterations, and the quantitative metrics agree (skip 0 ties or very slightly leads in every measured cell). Each schedule's difference from the converged reference is the same — the two difference panels in every figure with a reference are identical — so the schedules follow the same convergence path. Dropping the granularity-0 iteration is safe.

Data and methods

  • Datasets. lilly_ds8 and lilly_ds4: the NSI D01788 autoinjector scan preprocessed at downsample (8,8) with view subsample 8 (sinogram 225×235×187, recon 187×187×286) and at (4,4)/4 (sinogram 450×470×374, recon 374×374×667). z62: the ORNL Versa Z62 cylinder (partition-study cache, 201 views, recon 512×512×640).
  • Reconstruction. Cone-beam MBIR with transmission_root weights; sharpness ∈ {1.0, 2.0} set before auto_set_regularization_params (auto-regularization then frozen). Both schedules run the plain library solver with the same seed, so subset partitions match. Volumes were captured at 15, 20, and 30 iterations in one continuous run per variant.
  • Reference. Where shown, the leftmost column is a 150-iteration default-schedule reconstruction of the same cost function — effectively the converged answer both schedules are heading toward. (lilly_ds4 at sharpness 2.0 has no cached reference; that comparison is image-only.)
  • Metric. The tables give NRMSE vs the reference in percent — the relative RMS difference from the converged answer over the interior (disk of 0.85× the recon radius, 10% of slices excluded at each axial end). Lower = closer to converged; 5% means the reconstruction differs from the reference by 5% RMS.
  • Display window. Every figure of a dataset uses the SAME grayscale window: the 1st–99th percentile of that dataset's sharpness-1.0 reference volume. Each figure title shows the window and the full data min/max.
  • Volumes. All captured volumes and references are in depot at /depot/bouman/data/mbirjax_metrics/slice_parity/ (recons/, refs/) for inspection with slice_viewer.

What to look for

Each figure has two view groups — an axial mid-slice (top) and a coronal mid-cut (bottom). Within a group, the upper row shows the reconstructions (reference | default | skip 0) and, directly below the default and skip 0 reconstructions, their difference from the 150-iteration reference (default − reference, skip 0 − reference). So each difference image sits under the reconstruction it belongs to; there is nothing under the reference itself. The difference images use one shared color scale per dataset (the colorbar at the right of each figure), set from the 99th percentile of the whole-volume error so the scale is representative; the bright axial-end flash zones exceed it and may clip.

Between figures, the sharpness setting and iteration count change, labeled by the colored chips in each figure heading (sharpness 1.0 is blue, sharpness 2.0 is orange; the gray chip gives the iteration count). The grayscale recon window is fixed across all figures of a dataset (see Methods). lilly_ds4 at sharpness 2.0 has no reference, so it shows the two reconstructions only.

  • The two difference panels are the point: default − reference and skip 0 − reference are visually identical in every figure — the two schedules are converging to the same place at the same rate. Any coherent structural difference between them would argue against dropping the iteration; none appears.
  • What the difference panels show is where each reconstruction still differs from the converged reference at this iteration count: near-zero (gray) through the well-converged interior, with signed error at high-contrast edges and, in the coronal cuts, strong bands at the axial ends.
  • Bands at the axial ends (top/bottom of the coronal cuts): the cone-beam flash zones — large, un-converged, and clipping the diff scale; excluded from the metric and addressed separately by the flash-remediation work.
  • The cone fan-plane (center-slice) effect: on lilly_ds4 sharpness 2.0 it shows as a mid-height band in the direct skip 0 − default difference in the zoom section below (the sharpness-2.0 figures here have no reference, so they show reconstructions only). Both schedules have the same noise spike there; it stands out only because the two runs' noise realizations diverge most where voxels are least anchored.

Center-slice (fan-plane) zoom — lilly_ds4 sharpness 2.0

In the direct skip 0 − default difference (third panel, with its own colorbar), a band appears at mid-height, z ≈ 329–331: the cone fan plane (the volume midpoint is 333; the offset matches the detector row offset). The rightmost panel below plots per-slice axial second-difference RMS — the "slice decoupled from its neighbors" noise signature — for both schedules. Both show the same sharp spike at the fan plane, and the two curves essentially coincide: skip 0 is higher by less than 1% at 15 iterations and less than 0.1% at 30, against a ±20% slice-to-slice variation of the same metric. The center-slice effect is a property of the surrogate and the cone geometry, not of the schedule; the difference image highlights that band only because the least-anchored voxels are where two otherwise-equivalent runs diverge most. (This figure deliberately uses a much tighter window than the main figures, to make the noise texture visible.)
